# Design spec

`acv_spec_v2_1.json` is the shipped design spec of record (v2.1 base) for
agent-code-validation. It is the functional target for the plugin.

The v2.3 runtime/browser/container extension layer is **deferred** (see
`ROADMAP.md`, Phase 6) and is intentionally not implemented here.

This file is a tracked copy of the spec originally produced under the
(gitignored) research pipeline. Treat this copy as authoritative for the
shipped plugin.
